Centralized application state (Zustand): `useAppStore` holds the current user (with roles/permissions), locale, and theme name; `selectors.ts` exposes typed selectors. The access token is never in this store — it lives only in the module-scoped `shared/api/tokenStore.ts`. Only `features/authentication` writes session state — everything else reads via `useAuth()`/`useAuthorization()`, which read this store internally.
